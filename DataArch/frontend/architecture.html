Core Pipeline
End-to-end document processing in one click — from raw files to queryable intelligence
📄
1. Ingest
Parse PDF, Excel, Word, CSV, and email files. Extract raw text with format-specific parsers.
PyMuPDF · openpyxl · python-docx
🧠
2. AI Extraction
Claude reads every document and extracts structured entities, attributes, and relationships using tool_use.
Claude Sonnet 4.5 · tool_use
🏷️
3. Ontology Map
Each entity is classified into the PE ontology: vendor, customer, employee, product, and more. Names are normalized.
Claude + Pydantic validation
🗄️
4. Schema Gen
Auto-generate a normalized PostgreSQL schema with FK relationships, indexes, and multi-tenant isolation.
Type inference · topo sort
💾
5. DB Load
UPSERT entities into PostgreSQL. Type-aware value transformation for currency, dates, and booleans.
SQLAlchemy · ON CONFLICT
🔍
6. Embed
Generate vector embeddings for every entity. Stored in PostgreSQL via pgvector for semantic search.
Voyage AI · pgvector
🤖 AI Capabilities — Claude + Voyage AI
Document Extraction — Claude reads unstructured documents and extracts entities, amounts, dates, and attributes using structured tool_use
Entity Classification — Each entity is mapped to the PE ontology (vendor, customer, etc.) with confidence scores and normalized names
SQL Analytics Agent — Ask business questions in plain English. Claude generates SQL, executes it read-only, and synthesizes a natural language answer
Semantic Search — Voyage AI generates 1024-dim embeddings for every entity. Search across the portfolio with natural language queries via pgvector cosine similarity
Document-Type Detection — Auto-detects invoices, contracts, financial statements, and HR documents for specialized extraction prompts
Answer Synthesis — After SQL results are returned, Claude generates clear, executive-friendly answers from raw data tables

Architecture Layers
How the system is organized — from user interface to data storage
🖥️ Presentation Layer
Vanilla HTML/CSS/JS with a custom design system ("Crisp Precision White"). Six pages: Ingestion, Ontology Registry, Schema Builder, Data Flow (D3.js), AI Analytics, and Portfolio Intelligence. Zero build step — just serve static files.
🌐 API Layer (58 endpoints)
FastAPI with 10 modular route files: auth (7), ingest (6), ontology (4), schema (3), dataflow (2), database (6), AI (3), portfolio (7), entities (4), admin (9). CORS middleware, auth dependencies, and request validation.
⚙️ Service Layer
Central ontology service with 5-min TTL cache, providing dynamic config to all pipeline modules. Audit logging service for non-blocking write-behind logging. Auth service with JWT token management and RBAC enforcement.
🔧 Pipeline Layer (6 stages)
Modular pipeline: parsers → LLM extraction → ontology classification → schema generation → DB creation → embedding. Background job runner with per-step status tracking. Smart chunking for long documents.
💾 Data Layer
PostgreSQL 16 with pgvector. SQLAlchemy 2.0 connection pooling with pre-ping health checks. Dynamic entity tables per ontology type, plus system tables for users, API keys, audit logs, and pipeline jobs. Alembic for migrations.
🏗️ Infrastructure Layer
Docker Compose with health checks on both API and database. Container entrypoint runs migrations → seed → serve. Environment-based configuration via .env files. One-command startup with start.sh.
